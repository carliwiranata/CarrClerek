CASH VIEWER V8 - GITHUB PAGES

1. Buat repository baru di GitHub, misalnya: cash-viewer-v8
2. Upload SEMUA isi folder ini ke repository (index.html, jszip.min.js, .nojekyll).
3. Pastikan index.html berada di folder utama repository, bukan di dalam folder lain.
4. Buka Settings > Pages.
5. Pada Build and deployment pilih Source: Deploy from a branch.
6. Branch: main, folder: / (root), lalu Save.
7. Tunggu sampai GitHub Pages memberikan alamat https://USERNAME.github.io/cash-viewer-v8/
8. Buka alamat tersebut di Chrome Android atau Safari iPhone.

PENTING UNTUK IPHONE:
- Harus dibuka melalui HTTPS dari GitHub Pages.
- Saat Safari meminta izin lokasi, pilih Allow.
- Jika lokasi sebelumnya ditolak: Settings > Safari > Location, lalu izinkan untuk situs tersebut.
- Jangan menjalankan index.html langsung dari Files/ZIP karena Geolocation iPhone membutuhkan secure context.
